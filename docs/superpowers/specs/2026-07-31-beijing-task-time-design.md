# 任务列表北京时间展示设计

## 目标

任务列表中的创建时间固定显示为北京时间，格式为
`YYYY-MM-DD HH:mm:ss`。数据库继续保存 UTC，不修改历史数据、
数据库结构或其他时间字段的存储语义。

## 根因

应用写入带 UTC 时区的 `datetime`，但 SQLite 读取后返回无时区
`datetime`。当前服务端模板直接调用 `isoformat()`，SSE 也发送
无时区 ISO 字符串；浏览器因此把 UTC 小时当成本地小时展示。

## 设计

新增一个展示层时间格式化函数：

- 带时区时间先转换到 `Asia/Shanghai`。
- 无时区时间按 SQLite 返回的 UTC 解释，再转换到
  `Asia/Shanghai`。
- 输出固定格式 `%Y-%m-%d %H:%M:%S`。

首屏模板通过同一格式化函数展示 `task.created_at`。SSE 任务快照保留
现有 `created_at` 字段，并新增 `created_at_display`；前端任务列表直接
使用该展示字段，避免依赖访问者浏览器时区和区域格式。

## 边界

- 不修改数据库模型、迁移或 UTC 写入逻辑。
- 不改变任务排序。
- 不改变日志时间展示。
- 不改变现有 SSE 原始时间字段，避免影响兼容性。

## 测试

- 格式化函数正确处理带 UTC 时区的时间。
- 格式化函数把无时区时间视为 UTC。
- 首屏 HTML 显示固定北京时间格式。
- SSE 任务快照包含相同的北京时间展示值。
- 前端实时任务渲染使用 `created_at_display`。
