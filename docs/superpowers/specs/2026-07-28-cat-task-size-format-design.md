# cat_task 文件大小格式设计

## 目标

改善 `cat_task` 文件清单的可读性，以 KB 和 MB 代替当前的字节数展示。

## 显示规则

- 使用十进制单位：`1 KB = 1000 B`，`1 MB = 1000 KB`。
- 文件大小小于或等于 `1000 KB` 时，以 KB 显示。
- 文件大小大于 `1000 KB` 时，以 MB 显示。
- 数值统一保留两位小数。
- 缺失或无法读取大小的文件继续显示 `[missing]`。

示例：

```text
  0.50 KB  task.log
  1000.00 KB  result.json
  1.25 MB  mineru_result.zip
```

## 实现范围

在 `task_diagnostics` 中增加一个仅负责格式化字节数的内部函数，并由
`format_task_snapshot()` 调用。文件收集、实际大小计算、ZIP 内容和打包逻辑不变。

## 测试

单元测试覆盖：

- 普通 KB 文件；
- 恰好 `1000 KB` 的临界值仍显示 KB；
- 超过 `1000 KB` 后显示 MB；
- 缺失文件格式保持不变。
